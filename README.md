### 2. [Employee Manager – QA Portfolio Project 🧪](https://github.com/mstobrawa/employee-manager-qa)
A software testing project covering manual, API, and UI testing of an employee management application.

* **Stack:** Python, pytest, Selenium, Postman, TestRail, Jira.
* **Manual testing:** 29 test cases using Equivalence Partitioning, Boundary Value Analysis, and Decision Tables.
* **API testing:** 13 automated tests using pytest and requests, covering positive and negative scenarios.
* **UI testing:** 7 Selenium tests using the Page Object Model with HTML reports.
* **Defect reporting:** 3 defects reported in Jira, including a session token vulnerability.
